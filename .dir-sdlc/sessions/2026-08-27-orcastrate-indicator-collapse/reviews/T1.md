## Advisory findings

1. **`marksInTab()` recognises a mark only if it is `aria-hidden="true"` or carries `data-status`** (`src/renderer/src/pods/PodTab.test.tsx`, helper above the running-dot tests). A re-introduced decorative element that is neither — a plain `<span className={styles.pulse} />` — would slip past. It catches the realistic regression, since the retired indicator was `aria-hidden`, so this is a narrow gap rather than a hole. *Category: test coverage.*

2. **The "belongs to the query, not to some later rule" check anchors on the wrong thing** (`src/renderer/src/pods/PodBar.styles.test.ts`, the `sets animation: none inside that query` test). It compares against `tail.indexOf('@media', 1)`, which is `-1` today only because the reduced-motion block happens to be last in the file. If a non-`@media` rule were later appended below it, an `animation: none` in that new rule would satisfy the check. Anchoring on the block's closing brace instead would keep the assertion honest as the file grows. *Category: test coverage.*
