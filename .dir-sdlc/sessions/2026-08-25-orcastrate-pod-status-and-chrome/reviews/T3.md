## Blocking finding — escalated as E1

**`--oc-status-stopped: #8f8577` does not separate from `--oc-status-idle` by lightness,
so a stopped lane does not survive greyscale.** `src/renderer/src/styles/tokens.css:65`,
and the comment above it at 59-64 asserting the opposite. Violates criterion 3, whose
refusal to relax the distinctness assertion rests on exactly this claim.

Measured by the reviewer with a WCAG relative-luminance computation, and **independently
recomputed by the orchestrator**, same figures:

| Pair | Contrast ratio |
|---|---|
| `stopped` vs `idle` | **1.022** (Y 0.2395 vs 0.2333) |
| `stopped` vs `closed` | 2.220 |
| `closed` vs `idle` — the precedent the criterion cites | 2.173 |

Hue separation (warm vs cool) is real and survives common red-green CVD. Lightness
separation is effectively zero, so under greyscale or achromatopsia `stopped` and `idle`
read as the same swatch. The hygiene assertion passes because it tests string
inequality, not perceptual separation — it cannot catch this.

### Ranked remediation options

1. **Re-pin `--oc-status-stopped` lighter, e.g. `#c0b39d`, amending the value in both the criterion and the contract.** Keeps the warm-neutral intent and the family boundary while buying real lightness separation: 1.80 vs `idle` and 3.90 vs `closed` (orchestrator-verified). Trade-off to weigh: lightening makes `stopped` more prominent, pushing against the "quiet, must not compete with `waiting`" rationale in the same comment. Darkening is not an alternative — `#5f584d` measures 1.15 against `closed`, trading one collision for a worse one. Evidence: `judgment`.
2. **Keep `#8f8577` and correct criterion 3's stated basis to hue-only separation,** pushing the greyscale obligation onto the two consuming tasks, which criterion 7 already frames as their responsibility. No code change; the spec stops claiming something measurably untrue. Evidence: `repo` — `tokens.css:56` records that `closed` carries a second, non-colour signal for the same reason, so the pattern exists here already.
3. **Replace hygiene's `not.toBe` inequality with a measured luminance-or-hue separation assertion,** so the next status widening cannot repeat this silently. Only viable on top of option 1 — against the current value the new assertion would fail immediately — and it widens a hygiene rule beyond this task. Evidence: `judgment`.
