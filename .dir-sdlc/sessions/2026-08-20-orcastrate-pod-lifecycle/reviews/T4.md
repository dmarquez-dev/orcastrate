## Advisory findings

1. **`makeStubPod`'s default `status` moves `'idle'` → `'closed'` repo-wide**
   (`test-utils/stub-api.ts:125-129`). Every suite in the repo is green today, but this is silent
   leverage over fixtures outside T4's ownership. **Carried forward to T5 and T6 at dispatch** so
   neither is surprised that its default Pod is now born closed.
2. **`isPodOpen` is exported from `workspace-provider.tsx:161` with no consumer.** The barrel comment
   at `state/index.ts:17-22` says it stays there "for the tests that sweep every status through it",
   but no test imports it — the sweep correctly uses its own `OPENNESS` table to stay an independent
   oracle rather than a tautology. The comment overstates its use.
3. **The red-first stand-in `(_status) => false` is adequate for I2 but is not a general regression
   harness.** It faithfully reproduces the old behaviour for the never-opened path I2 exercises, but
   not the old latch after an `openPod` call.
