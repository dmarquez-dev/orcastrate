## Findings

**Blocking: none.** No contract violation: no file outside the ownership set,
no edit to `contracts/correctness-sweep.ts`, and no scratch write outside T4's
own directory.

**Advisory 1 — the added import is an unnamed edit.**
`failure-paths.e2e.test.tsx:69` adds
`import { HELM_SAFETY_TEST_IDS } from '../helm/test-ids';`. Criterion 18 asks
that further edits to that file be named in the report; this one was not. It is
required by the new test and harmless. No options — advisory.

**Advisory 2 — two unreachable holes in Q1's "never both / never neither".**
Both depend on `lastAction === 'compare'` surviving into a state the comparison
surface cannot carry. (a) If `draft` became null while a compare error stood,
`HelmPanel.tsx:126` would render no comparison at all while `:84` still
suppresses the banner — the message would vanish. (b) If `refreshScopes` failed
while `lastAction === 'compare'`, `loadError` and `actionError` take the same
sentence and it would print in both surfaces. The reviewer checked reachability
for both: only `loadDocument` nulls `draft`, and both its entry points set
`lastAction` to `'other'` first; `refreshScopes` is reached only from
`retainHelm`, called from `useEffect(..., [store])` at `panel-provider.tsx:231`,
which runs at mount when `lastAction` is still `null`. **Neither is reachable
today**, so neither is a criterion failure — worth noting only because the
invariant rests on that reachability argument rather than on the code's own
shape. No options — advisory.

**Advisory 3 — `'other'` and `null` are behaviourally identical.**
`lastAction` is three-valued but only `'compare'` is ever tested (`:73`). A
boolean would carry the same information. Purely a naming/shape preference; the
three-valued form reads more clearly as a latch and costs nothing.
No options — advisory.
