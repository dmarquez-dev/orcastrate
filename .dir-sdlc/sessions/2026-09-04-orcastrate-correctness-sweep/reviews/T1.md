**Advisory 1 — the leaf scan's import regex is narrower than its docblock claims.**
`tests/unit/ipc/failure-leaf.test.ts:41-47` uses
`/^import[\s\S]*?from\s*'[^']*';/gm`, which requires a `from` clause, single
quotes and a trailing semicolon. A bare side-effect import (`import '../pod';`)
has no `from` clause and would not be matched at all, so the scan would report
zero imports and pass. Double-quoted or semicolon-less specifiers evade it the
same way. The criterion is met as written — the scan asserts the properties and
was shown able to fail — but the guard does not cover every shape it implies.
No options — advisory.

**Advisory 2 — process note, not a finding against the diff.**
Verifying criterion 8 is harder than it looks: the repo's `typescript` package
is a stub (`node_modules/typescript/lib/` holds only `tsc.js`, `version.cjs`,
`getExePath.js`) with no compiler API, so `ts.createScanner` is unavailable to
any future reviewer taking that route. No options — advisory.
