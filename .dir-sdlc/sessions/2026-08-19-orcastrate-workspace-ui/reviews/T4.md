## Advisory findings

1. `PodBarPanel.tsx:74` drops the optimistic order on **success** too, before T5's refetch necessarily lands. Likely invisible since `store.ts:490` applies each updated Pod as it returns, but a slow round trip could flash the pre-drag order for a frame.
2. `PodBar.module.css` uses bare `2px`/`3px` box-shadow spreads, `letter-spacing: 0.04em`, and `font-weight: 700`/`600`. No token exists for hairline width, tracking, or weight, and **peers do the same** (`transcript/Transcript.module.css:91`, `lanes/LaneRail.module.css:25`) — so this is a token-set gap rather than a T4 deviation. Adding those tokens is a T3 change.
3. `NewPodDialog.tsx:126` sets `aria-modal="true"` but the dialog has no focus trap and the background is not `inert`; Tab can reach the Pod bar behind the opaque scrim. Outside criteria 7–9 but relevant to the accessibility floor the task set itself.
4. The bypass badge carries the same sentence three ways — `aria-label`, `title`, `.srOnly` child. Correct under `role="img"`, but the redundancy is load-bearing only if the role were dropped; a comment explaining why all three are present would protect it.
5. `NewPodDialog.tsx:118` calls `event.stopPropagation()` on Escape at the dialog root, preventing any ancestor Escape handler from seeing the key while open. Fine today; it will silently swallow a future global shortcut.
6. **Keyboard reorder judged sound, no finding.** `Ctrl`/`Cmd`+Arrow handled at `PodTab.tsx:82`, advertised via `aria-keyshortcuts`, focus restored to the moved tab through `requestAnimationFrame` so repeated presses keep moving the same Pod, and the new position announced through an `aria-live="polite"` region. Unmodified arrows do roving focus.
7. Status is carried by color, shape (`data-status`: hollow ring idle, haloed waiting, square beached, filled running) and a screen-reader status word — satisfying "color is never the only carrier of meaning". One gap: `running` and the default filled dot share a shape, so running versus any future unlisted status would rest on color alone for sighted users if the status union widens.
