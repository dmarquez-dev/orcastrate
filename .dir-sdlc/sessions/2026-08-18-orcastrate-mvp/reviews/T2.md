## The `env` question — asserted in both directions, now settled

`envReplacesEnvironment: true`. **`env` replaces.**

Round 0 concluded "merges" from `PATHLEN=2725`, which discriminates nothing
because Git Bash rebuilds `PATH` regardless of what it inherits. The re-test set
`PROBE_INHERITED` on the probe's own process, passed only `{ PROBE_MARKER }`, and
the child reported `INHERITED=[] PASSED=[probe-env-marker]`.

The reviewer then settled it from the SDK source rather than a third
observation: `sdk.mjs` destructures `env: c = {...process.env}` — a destructuring
**default**, so the spread applies only when the caller omits `env`. A supplied
`env` is passed verbatim to the spawn. **`PodRunner` must pass
`{ ...process.env, ...envOverrides }`; this is mandatory, not tidiness.**
