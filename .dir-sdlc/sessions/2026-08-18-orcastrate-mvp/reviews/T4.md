## Targeted verifications

- **`env` (A)** — holds, and corroborated independently from the SDK source.
- **`@ts-expect-error` technique (B)** — wired and load-bearing. `tsconfig.node.json`
  includes `tests/**/*`, and the reviewer confirmed TypeScript 7.0.2 emits
  `TS2578` on an unused directive. Since `typecheck:node` passes today, both
  directives are suppressing real errors — which *is* the assertion. Making
  `acceptEdits` type-legal would turn them unused and fail the build.
- **Single `query()` (C)** — holds. The bridge call appears exactly once;
  `send()` throws `NOT_RUNNING` before `start()`, after `stop()` (which sets
  `stopped` synchronously), and after `#beach` (likewise). No path from `send()`
  reaches the bridge.
- **Abort race (D)** — proves what it claims: pending-before / settled-after,
  using a real `setTimeout(0)` so both the microtask queue and the timer phase
  drain, rather than merely settling.
- **`UNROUTED_LANE_ID = ''` (E)** — **fails loudly, safe.** `lane_id TEXT NOT NULL
  REFERENCES lanes(id)` with `foreign_keys = ON`, and `lanes.id` is a
  router-assigned uuid, so no row can have `id = ''`. An unrestamped event raises
  `CONFLICT` at `append` rather than persisting. Not a silent-corruption path.
- **`onMalformed` production path (F)** — **confirmed against the SDK source.**
  `sdk.mjs` does `try{r=ht(n)}catch(o){on(\`Non-JSON stdout: ${n}\`);continue}`,
  so an unparseable line is logged by the SDK and dropped before any consumer
  sees it. In production `onMalformed` fires only for values that parsed but
  failed `asEnvelope`. **Design-spec section 8's raw-line surfacing is not
  achievable from PodRunner** — the behavior exists, but in the SDK.
- **`PreToolUse` matcher (G)** — correctly formed. `'Agent|Task'` matches the
  SDK's documented pipe-separated form and the callback re-checks `tool_name`, so
  a loose matcher cannot cause a wrong rewrite. Whether the live CLI invokes the
  hook before dispatch remains **E3**, unproven.

**Divergence 5 (`RangeError` for an unsupported `permissionMode`) — judged
correct.** No frozen `PodRunnerErrorCode` describes "caller passed a value
outside the contract's own union", and adding one would violate criterion 1 — a
contract constraint, not a taste call. The path is unreachable from typed code.

## Advisory findings

Carried to Gate 3. No options attached.

- **1** — Tautological second assertion in the PATH test; it can only fail in a
  case the preceding assertion already caught. Reads as a stronger
  platform-specific check than it is.
- **2** — **`setPermissionMode` can reject with a non-`PodRunnerError`**
  (`RangeError`). **T7's IPC layer must not assume every rejection from a
  PodRunner method carries a `.code`.**
- **3** — Record the `onMalformed` caveat in the session's divergence record
  rather than leaving it in a `stream.ts` doc comment.
- **4** — `forwardSubagentText` is forwarded, not hard-set. The contract types it
  as literal `true` so typed callers cannot pass `false`, but an untyped IPC
  caller could. A literal in `buildSdkOptions` would make "always" unconditional
  at runtime.
- **5** — `sendToAgent()` is declared with zero parameters against the contract's
  `(agentId, text)`. Structurally assignable; naming them would document the
  Steer swap point.
- **6** — **`UNROUTED_LANE_ID` restamping is an unenforced obligation on T7.**
  The sentinel fails loudly, so this is not a correctness risk, but the failure
  appears as a `CONFLICT` at append time rather than at the boundary. A one-line
  assertion in T7's handler would move it earlier.

## Propagates to T7

- Restamp `UNROUTED_LANE_ID` with the Pod's Matriarch lane id before persisting;
  assert at the boundary rather than relying on the FK to catch it.
- Do not assume every PodRunner rejection is a `PodRunnerError` with `.code`.
- Handle the FK `CONFLICT` from a bad `lane_id` rather than swallowing it.
