## Advisory findings

Carried to Gate 3 for defer-or-act. No options attached — reviewers attach
options to blocking findings only.

- **A1** — `react`/`react-dom` in `devDependencies` is correct, not a compromise:
  they are bundled into the renderer chunk and electron-builder ships only
  `dependencies`, so promoting them would inflate the installer with dead code.
  Criterion 2 satisfied. (`package.json:31-32`)
- **A2** — `@types/better-sqlite3@9.6.0` against `better-sqlite3@13.0.3`, four
  majors apart. T1 typechecks clean, but **T3 writes real store code against
  those types and cannot edit `package.json`.** Highest-risk advisory of the set.
  (`package.json:22`)
- **A3** — `noUnusedLocals`/`noUnusedParameters` disabled repo-wide because
  frozen `contracts/event-store.ts:21` imports `PodStatus` unused. Neither flag
  is part of `strict`; per-file suppression of `TS6133` on an uneditable file
  does not exist, and the alternatives (a third tsconfig project, or unfreezing
  the contract) cost more than they return. Judged sound; revisit if the
  contracts are amended for another reason.
- **A4** — `"type": "module"` removal is correct: `out/preload/index.js` is CJS
  and self-contained, which a sandboxed preload requires. `window.ts:25` uses
  `__dirname`, consistent with that choice.
- **A5** — `jsdom` `EBADENGINE` warning is inert (no `engine-strict`); kept
  because sub-session 2 needs it and cannot edit `package.json`.
- **A6** — `.gitignore` ignores `build/` while `electron-builder.yml` sets
  `directories.buildResources: build`. The first icon or installer resource
  dropped there is silently untracked. Cheap to fix later; a real packaging trap.
- **A7** — `tsconfig.node.json` includes `probe/**/*`, which does not exist yet.
  Harmless; staged for T2.
- **A8** — Renderer chunk 555 kB, expected for an unsplit React bundle in a
  local Electron app. No action.
